# Scientific validation programme

This directory records the sequential investigation requested on 6 October 2026. The baseline is commit `7da18d1cbd36c40c48228118abb20a7b5ab032f4`. Later local competition changes are inventoried separately and must not be overwritten.

## Evidence policy

A recorded historical result is different from a newly executed experiment. A statistical association is different from a causal mechanism. Internal reproduction is different from independent replication. A simulation is different from physical measurement. Negative and inconclusive results are retained.

`progress.json` contains the authoritative item order, statuses, evidence and remaining dependencies. Completing a scoped investigation does not assert that its scientific hypothesis was confirmed. External replication, real-world impact and a Nobel nomination cannot be manufactured by this programme.
